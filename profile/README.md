# Façade

### Le site de votre commerce, déjà prêt.

Des sites web pour les commerces de proximité,<br>
créés pour eux et mis à jour sur simple demande par WhatsApp.

</div>

**Un site à votre image.** Votre commerce, vos photos, vos horaires et votre identité.

**Tout est compris.** Création, hébergement, nom de domaine et entretien dans un abonnement mensuel, sans engagement.

**Une demande, une mise à jour.** Envoyez vos changements par WhatsApp : carte, horaires, photos, actualités. Les modifications sont illimitées.
